
HealthHub is a comprehensive, user-friendly app designed to help individuals manage and track their mental health symptoms over time. By providing insightful data visualization and the ability to complete standardized mental health assessments, HealthHub empowers users to understand their mental well-being and make informed decisions. The app is accessible on smartphones, tablets, and desktop devices, ensuring a broad reach and ease of use.





Features:

User Authentication: Secure sign-up and login functionality using FirebaseAuth.

Data Visualization: Line charts display users' mental health scores over time, with the ability to view data for a week, month, or year.

Standardized Assessments: Users can submit daily assessments using well-known scales like PHQ-9, SHS, and GAD-7.

Profile Management: Users can update personal information including weight, height, allergies, and medical restrictions.

Notes: A section to add and save daily notes with a subjective score on how the day went.

PDF Export: Users can export their medical profile and mental health data as a PDF for sharing with medical professionals or caretakers.

Sidebar Navigation: Easy navigation through different sections of the app.

Design Considerations

UI/UX: The app features a simple color scheme (blue, white, black) and consistent design elements to ensure the interface is easy to navigate and not overwhelming.

Cross-Platform Compatibility: Developed using the Flutter framework, ensuring functionality across multiple platforms.

Security: User data is secured with Firebase authentication, and a minimum password length of six characters is enforced.


Tools & Technologies:

Frontend: Flutter framework and Dart programming language

Backend: Firebase for database management and user authentication
